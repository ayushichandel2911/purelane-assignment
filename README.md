A Shopify storefront implementation for the Purelane homecare brand, created as part of the AI Product Engineer assignment.

## Overview

Purelane is a plant-powered homecare brand focused on effective, safer, and environmentally conscious cleaning products.

This project recreates the provided Purelane homepage design as a custom Shopify theme.

## Features

- Custom Purelane hero section
- Featured products / collection
- Plant-powered ingredients section
- How It Works section
- Product benefits / proof section
- Best-selling product bundles
- Customer reviews
- Email signup section
- Custom Purelane footer
- Responsive desktop and mobile layout
- Custom styling and UI components
- Shopify Liquid section architecture

## Tech Stack

- Shopify
- Shopify Liquid
- HTML5
- CSS3
- JavaScript
- Shopify Theme CLI
- Git & GitHub
